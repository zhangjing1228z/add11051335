# add11051335

番茄专注 Web 应用

## 简介

本项目是一个基于番茄工作法（Pomodoro Technique）的专注计时 Web 应用，帮助用户通过「工作 25 分钟 + 休息 5 分钟」的循环模式提升效率、保持专注。

## 功能特性

- ⏱️ **番茄计时**：默认 25 分钟专注时段，支持自定义时长
- ☕ **休息提醒**：每个番茄结束后提示短休息（5 分钟）与长休息（15–30 分钟）
- 📊 **统计记录**：记录每日完成的番茄数量与专注时长
- 🔔 **通知提醒**：计时结束时通过声音/浏览器通知提醒
- 🌙 **简洁界面**：轻量、直观的 UI，专注于当下任务

## 快速开始

```bash
# 克隆仓库
git clone <repository-url>
cd add11051335

# 安装依赖并启动（根据实际技术栈调整）
npm install
npm run dev
```

启动后在浏览器中访问本地开发服务器地址即可使用。

## 使用说明

1. 设定当前要完成的任务
2. 点击开始，进入 25 分钟专注计时
3. 计时结束后短暂休息 5 分钟
4. 每完成 4 个番茄，进行一次 15–30 分钟的长休息
